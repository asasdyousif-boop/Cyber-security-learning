The Access Layer

Important Concepts

- Access switches forward frames based on MAC addresses.
- Each switch builds a MAC Address Table by learning source MAC addresses.
- VLANs divide a network into separate logical networks to improve security and performance.
- Port Security helps prevent unauthorized devices from connecting to the network.
- The Access Layer provides high-speed connectivity for end devices.
