Loops 

Loops are used to repeat a block of code multiple times.

1. for Loop

Used when the number of repetitions is known.

Syntax:

for (initialization; condition; update) {
    // Code
}

Example:

for (int i = 1; i <= 5; i++) {
    cout << i << endl;
}

Output: "1 2 3 4 5"

2. while Loop

Repeats code as long as the condition is true.

int i = 1;

while (i <= 5) {
    cout << i << endl;
    i++;
}

3. do-while Loop

Executes the code at least once before checking the condition.

int i = 1;

do {
    cout << i << endl;
    i++;
} while (i <= 5);

4. break Statement

Stops the loop immediately.

for (int i = 1; i <= 10; i++) {
    if (i == 5) {
        break;
    }

    cout << i << endl;
}

5. continue Statement

Skips the current iteration and moves to the next one.

for (int i = 1; i <= 5; i++) {
    if (i == 3) {
        continue;
    }

    cout << i << endl;
}

Important:

- "for": Used when repetitions are known.
- "while": Checks the condition before execution.
- "do-while": Executes at least once.
